👻 GhostScript — Haunted AI Terminal

A spooky, interactive terminal experience inspired by Halloween and the Ghost in the Machine open-source AI challenge.

📝 About the Project

GhostScript is a Halloween-themed web project that simulates a haunted computer terminal. Users can interact with a mysterious ghost, generate horror stories, summon spooky messages, and enjoy dark jokes through a terminal-style interface.

The project is built using HTML, CSS, and JavaScript. It combines a dark visual theme, animated effects, and interactive commands to create a fun and beginner-friendly web experience.

Note: This version uses predefined JavaScript responses. Integration with a real open-weight AI model is a planned enhancement.

✨ Features

👻 Haunted Terminal: Interact with a spooky terminal interface.

📖 Ghost Story Generator: Display random horror stories.

👁 Summon a Ghost: Receive mysterious ghost messages.

💀 Dark Jokes: Enjoy spooky programming jokes.

❓ Help Command: View available terminal commands.

🧹 Clear Terminal: Clear previous messages.

🌌 Animated Background: Enjoy a dark, atmospheric design.

📱 Responsive Design: Works on desktop and mobile screens.

📴 Offline Access: The current version works locally without an internet connection after the files are saved.

🚀 How to Run the Project

Step 1: Download or Clone the Repository

git clone YOUR_REPOSITORY_URL

Replace YOUR_REPOSITORY_URL with your actual GitHub repository URL.

Alternatively, download the project files directly.

Step 2: Open the Project

Open the GhostScript folder in Visual Studio Code.

Step 3: Run the Website

Open index.html in your web browser.

You can also install the Live Server extension in VS Code, right-click index.html, and select Open with Live Server.

No additional packages or dependencies are required.

🌱 Open Innovation and Future AI Integration

GhostScript is inspired by the idea of bringing open-source AI into creative web applications.

The current prototype runs entirely in the browser and does not send prompts to an external AI service. Its responses are predefined rather than AI-generated.

Future improvements could include:

Integrating Ollama with an open-weight language model such as Qwen or Gemma.

Generating original horror stories from user prompts.

Supporting local inference without an internet connection after model installation.

Keeping prompts and generated stories on the user's machine.

Allowing users to switch between compatible models.

These additions would demonstrate how open-weight AI can provide more control, privacy, and flexibility.
